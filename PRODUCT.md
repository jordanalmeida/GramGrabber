# Product

## Register

brand

## Users

Developers and power users who archive video content from Telegram channels they follow. They are comfortable with a terminal today, but a GUI version is planned — the brand must read as a polished product, not a hacker toy. Context: they arrive from Google searches like "telegram channel video downloader" or from the GitHub repo.

## Product Purpose

GramGrabber is a free, open-source CLI (Go) that downloads videos from Telegram channels using the official MTProto API — 8 parallel threads, resumable downloads, interactive channel picker. The landing page exists to (1) rank on search for Telegram video downloading, (2) convert visitors into users via a clear tutorial, and (3) attract contributors/stars on GitHub. Success = organic installs and GitHub stars.

## Brand Personality

Swift, precise, dependable. "Night flight": a paper plane crossing a deep cobalt sky — instrument-panel calm, not neon-hacker noise. Copy is confident and concrete (real numbers, real commands), never hype.

## Anti-references

- Sketchy "free downloader" sites: ad-choked, fake download buttons, popups.
- Neon terminal-hacker aesthetic (green-on-black, glitch effects) — the CLI is the current form factor, not the identity; a GUI is coming.
- Generic SaaS template: identical card grids, gradient text, hero-metric blocks.

## Design Principles

1. **Show the product working** — an animated, truthful terminal demo beats screenshots of nothing.
2. **The tutorial IS the conversion funnel** — every step copy-pasteable, zero ambiguity.
3. **Earn trust like open source does** — link the code, name the license, no dark patterns, no email gates.
4. **Fast page for a fast tool** — static HTML, no framework runtime, inline critical CSS; performance is brand proof.
5. **SEO is structural, not decorative** — semantic headings, JSON-LD (SoftwareApplication/HowTo/FAQ), hreflang EN↔PT-BR.

## Accessibility & Inclusion

WCAG AA minimum: body text ≥7:1 on the dark surface, muted text ≥4.5:1, full keyboard navigation, `prefers-reduced-motion` alternatives for the terminal animation, parallax and canvas scene. Page ships in English (default) and Brazilian Portuguese with proper `lang` and hreflang.
